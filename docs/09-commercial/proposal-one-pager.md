# Propuesta Ejecutiva De Primera Ronda

## Qué Se Construye

Una primera versión productiva para Laboratorio Dental Tláhuac con sistema administrativo privado, sitio web corporativo, módulo web responsive/PWA para repartidores, etiquetas QR o código, impresión básica desde navegador y evidencia de entrega.

## Qué Problema Resuelve

Reduce la dependencia de Excel y centraliza la operación diaria: clientes, doctores, clínicas, órdenes, estados, pagos, saldos, dashboard, entregas y evidencia de recibido.

## Qué Incluye

- Sistema administrativo privado.
- Login, usuarios, roles y permisos.
- Clientes, doctores, clínicas y doctores internos.
- Órdenes de trabajo dental.
- Estados e historial.
- Pagos, abonos y saldos calculados.
- Dashboard operativo básico.
- Sitio web corporativo en `laboratoriodentaltlahuac.com`.
- Etiquetas QR o código por orden.
- Impresión básica desde navegador.
- Módulo web responsive/PWA para repartidores.
- Escaneo desde celular.
- Firma o fotografía de recibido.
- Historial de entregas.
- QA, despliegue, capacitación básica y documentación.

## Qué No Incluye

- Migración completa del histórico del Excel.
- Inventario avanzado.
- Proveedores, compras y cuentas por pagar.
- CFDI/facturación.
- Reportes avanzados.
- WhatsApp automatizado.
- App móvil nativa.
- Geolocalización avanzada u optimización de rutas.
- Hardware, impresoras, etiquetas físicas, lectores o consumibles.
- Soporte indefinido.

## Beneficios

- Operación más ordenada y trazable.
- Mejor seguimiento de órdenes.
- Mayor claridad en pagos y saldos.
- Evidencia de entrega centralizada.
- Presencia digital formal.
- Base lista para crecer por fases.

## Fases

1. Fase 0 — Planeación y documentación: completada.
2. Fase 1 — Sistema administrativo MVP: implementada y validada en QA local.
3. Fase 2 — Sitio web corporativo: pendiente.
4. Fase 3 — Repartidores, entregas y etiquetas: pendiente.
5. Fase 4 — QA, capacitación y despliegue: pendiente/cierre.
