# Guion Ejecutivo De Demo

## Objetivo De La Demo

Mostrar al cliente que el MVP administrativo ya permite controlar la operación principal del laboratorio y explicar cómo la primera ronda lo llevará a producción con sitio web, repartidores, etiquetas y evidencia de entrega.

## 1. Contexto

- Presentar el objetivo del proyecto.
- Explicar que el sistema busca reducir dependencia de Excel.
- Aclarar que la demo muestra el MVP administrativo validado en QA local.

## 2. Problema Actual

- Operación dispersa en Excel.
- Dificultad para consultar estados, pagos y saldos.
- Falta de trazabilidad completa de cambios y entregas.
- Evidencia de entrega no centralizada.

## 3. Login

- Mostrar acceso privado.
- Explicar que el sistema usa usuarios, roles y permisos.
- Mencionar que el sistema administrativo no es público.

## 4. Dashboard

- Mostrar resumen operativo.
- Mostrar métricas básicas de clientes, órdenes y cobranza.
- Explicar que ayuda a revisar prioridades del día y saldos pendientes.

## 5. Clientes, Doctores Y Clínicas

- Mostrar listado de clientes.
- Crear o consultar un doctor.
- Crear o consultar una clínica.
- Mostrar doctores internos asociados a una clínica.

## 6. Órdenes

- Crear o consultar una orden de trabajo dental.
- Mostrar datos principales de la orden.
- Cambiar estado operativo.
- Explicar que el historial conserva los cambios relevantes.

## 7. Pagos Y Saldos

- Registrar un abono.
- Mostrar saldo calculado.
- Mostrar cancelación de pago con motivo.
- Explicar que los pagos cancelados no cuentan para el saldo.

## 8. Historial

- Mostrar historial de estados de una orden.
- Explicar la importancia de trazabilidad operativa.
- Relacionar el historial actual con el futuro historial de entregas.

## 9. Visión Futura De Repartidores Y Etiquetas

- Explicar la etiqueta QR o código por orden.
- Mostrar el flujo objetivo: asignar entrega, escanear desde celular, capturar evidencia y cerrar entrega.
- Aclarar que será una app web responsive/PWA, no una app móvil nativa.
- Aclarar que la impresión básica será desde navegador y que el servicio local de impresión dependerá de validar hardware.

## 10. Sitio Web Corporativo

- Presentar el objetivo del sitio en `laboratoriodentaltlahuac.com`.
- Explicar secciones esperadas: servicios, contacto, ubicación e información institucional.
- Aclarar que el sitio público estará separado del sistema privado.

## 11. Beneficios

- Menor dependencia de Excel.
- Información centralizada.
- Mejor seguimiento de órdenes.
- Mayor claridad en pagos y saldos.
- Entregas con evidencia.
- Presencia digital formal.

## 12. Próximos Pasos

- Revisar paquete comercial.
- Confirmar alcance incluido y exclusiones.
- Cerrar precio y forma de pago.
- Priorizar sitio web vs repartidores/etiquetas.
- Definir calendario de la siguiente fase contratada.
