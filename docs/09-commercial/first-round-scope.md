# Alcance De Primera Ronda

## Objetivo

Cerrar una primera ronda de implementación que permita al Laboratorio Dental Tláhuac operar el MVP administrativo en producción, presentar su sitio web corporativo y habilitar un flujo inicial de repartidores, etiquetas y evidencia de entrega.

## Incluido

- Sistema administrativo privado.
- Login privado, usuarios, roles y permisos.
- Seguridad con cookie HttpOnly y protección CSRF/XSRF.
- Sitio web corporativo en `laboratoriodentaltlahuac.com`.
- Clientes, doctores y clínicas.
- Doctores internos para clínicas.
- Órdenes de trabajo dental.
- Estados de órdenes.
- Historial de estados.
- Pagos, abonos y saldos.
- Cancelación de pagos con motivo.
- Dashboard operativo básico.
- Etiquetas por orden.
- QR o código por orden.
- Impresión básica de etiquetas desde navegador.
- Módulo web responsive/PWA para repartidores.
- Escaneo QR/código desde celular.
- Asignación de entregas.
- Firma o fotografía de recibido.
- Nombre de quien recibe.
- Historial de entregas.
- QA.
- Despliegue.
- Capacitación básica.
- Documentación.

## No Incluido

- Migración completa del histórico del Excel.
- Inventario avanzado.
- Proveedores.
- Compras.
- Cuentas por pagar.
- CFDI/facturación.
- Reportes avanzados.
- Exportaciones complejas.
- WhatsApp automatizado.
- App móvil nativa.
- Geolocalización avanzada.
- Optimización de rutas.
- Integración avanzada con mapas.
- Hardware, impresoras, etiquetas físicas o lectores.
- Servicio local de impresión sin validación previa de hardware.
- Soporte indefinido.

## Alcances Opcionales Para Cotización Separada

- Migración parcial o carga inicial acotada desde Excel.
- Reportes adicionales.
- Exportaciones específicas.
- Servicio local de impresión, sujeto a validación de impresora, sistema operativo, red y formato de etiquetas.
- Automatizaciones de comunicación.
- Geolocalización o mapas.
- Soporte posterior a la puesta en producción.

## Nota Comercial

El alcance incluido está diseñado para cerrar una primera versión productiva. Cualquier cambio mayor, integración externa, carga histórica completa o módulo no listado como incluido deberá revisarse y cotizarse por separado.
