# Supuestos Y Exclusiones

## Supuestos

- El sistema será web.
- Los repartidores usarán web responsive/PWA desde celular.
- La impresión básica desde navegador está incluida.
- El servicio local de impresión queda condicionado a validación de hardware.
- El cliente entregará logo, textos, datos de contacto, ubicación y servicios.
- El cliente proporcionará acceso a dominio/DNS o coordinará los cambios necesarios.
- El cliente validará los flujos con usuarios reales.
- Los cambios mayores se cotizarán aparte.
- Las fotos y firmas tendrán almacenamiento razonable.
- El uso inicial considera rol Admin y roles futuros configurables.
- La puesta en producción requiere credenciales, variables de entorno y ambiente definidos.
- La capacitación incluida es básica y enfocada en los flujos de la primera ronda.

## Exclusiones

- Inventario avanzado.
- Proveedores.
- Compras.
- Cuentas por pagar.
- CFDI/facturación.
- Migración completa del Excel.
- Reportes avanzados.
- Exportaciones complejas.
- App móvil nativa.
- Geolocalización avanzada.
- Optimización de rutas.
- Integraciones externas.
- WhatsApp automatizado.
- Hardware.
- Impresoras.
- Etiquetas físicas.
- Lectores.
- Consumibles.
- Soporte indefinido.

## Notas De Control De Alcance

- La migración completa del histórico del Excel no está incluida en la primera ronda.
- La impresión incluida es desde navegador; cualquier servicio local dependerá de validar impresora, sistema operativo, red y formato de etiqueta.
- La solución móvil propuesta para repartidores es web responsive/PWA, no app nativa.
- Cualquier integración con terceros debe cotizarse de forma independiente.
