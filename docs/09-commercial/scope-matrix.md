| Doctores internos | Sí | No | No | Doctores asociados a clínicas. |

| Saldos | Sí | No | No | Saldos calculados a partir de total y pagos vigentes. |

| Repartidores | Flujo inicial | Mejoras posteriores | No | Módulo web responsive/PWA incluido para flujo inicial. |

| WhatsApp | No | Fase posterior | Automatizado | Automatización de WhatsApp queda fuera de esta ronda. |
| App móvil nativa | No | No | Sí | Se propone web responsive/PWA, no app nativa. |
| Hardware | No | No | Sí | Impresoras, etiquetas físicas, lectores y consumibles son responsabilidad del cliente. |
