# Fase 2 - Migración Del Excel

## Objetivo

Migrar o poner en revisión información histórica del Excel sin comprometer la operación nueva.

## Estrategia

- Analizar hojas.
- Mapear hojas a clientes.
- Mapear filas a órdenes.
- Detectar pagos numéricos.
- Preservar notas libres.
- Marcar inconsistencias para revisión.

## Reglas

- No migrar sin validación.
- No confiar ciegamente en saldos manuales.
- Conservar datos originales relevantes.
- Recalcular saldos cuando los pagos sean detectables.

## Criterios De Salida

- Mapeo de hojas documentado.
- Casos ambiguos identificados.
- Importación en modo revisión disponible o planificada.
- Datos históricos no rompen el flujo operativo nuevo.
