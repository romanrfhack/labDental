# Próximos Pasos

1. Revisar paquete comercial y documentos contractuales base.
2. Ejecutar demo con cliente usando la agenda de reunión.
3. Confirmar alcance incluido, opcional y fuera de alcance.
4. Completar precio, forma de pago, fechas estimadas y firmas sin inventar importes ni fechas.
5. Solicitar logo, textos, datos de contacto y validación de dominio/DNS.
6. Confirmar usuarios clave para validar flujos y probar demo.
7. Confirmar hardware, modelo de impresora y equipo para pruebas de impresión.
8. Priorizar sitio web vs repartidores/etiquetas.
9. Planear siguiente fase contratada y registrar cambios de alcance si aplica.

## Criterios De Validación

- Cada paso debe cerrar con documentación actualizada.
- Los cambios deben ser incrementales y no breaking.
- Las reglas de negocio deben validarse antes de automatizarse.
- Los cambios fuera de alcance deben pasar por control de cambios antes de implementarse.
