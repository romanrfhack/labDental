# Fase 3 - Inventario Y Proveedores

## Objetivo

Agregar control básico de materiales, proveedores y movimientos de inventario.

## Alcance

- Proveedores.
- Materiales.
- Movimientos.
- Stock mínimo.
- Alertas.

## Reglas Iniciales

- Los movimientos deben ser trazables.
- El stock mínimo genera alerta, no bloqueo.
- La relación automática entre orden e inventario queda pendiente de decisión posterior.

## Criterios De Salida

- Se pueden registrar proveedores y materiales.
- Se pueden registrar entradas, salidas, ajustes y mermas.
- El sistema alerta materiales bajo stock mínimo.
- La documentación de inventario queda actualizada.
