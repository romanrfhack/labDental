# Backup Y Restore

## Estado Actual

La base de datos está pendiente de definir. No existe estrategia final de backup hasta confirmar motor, hosting y operación productiva.

## Reglas Iniciales

- Los backups son obligatorios antes de migraciones.
- Se recomiendan backups diarios en producción.
- El restore probado será criterio futuro de operación.
- Los respaldos deben protegerse contra acceso no autorizado.

## Criterios Futuros

- Restaurar una copia en ambiente no productivo.
- Documentar tiempo estimado de recuperación.
- Verificar integridad después del restore.
- Confirmar retención mínima de backups.

## Próximos Pasos

- Definir motor de base de datos.
- Definir ubicación de backups.
- Definir política de retención.
