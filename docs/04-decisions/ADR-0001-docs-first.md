# ADR-0001: Adoptar Documentación Primero

## Estado

Aceptada.

## Contexto

El proyecto sustituirá progresivamente una operación basada en Excel. Sin documentación inicial, el sistema puede crecer de forma desordenada y con reglas implícitas difíciles de validar.

## Decisión

Adoptar documentación primero antes de crear código, proyectos, base de datos o infraestructura.

## Motivo

Evitar crecimiento desordenado y mantener trazabilidad de alcance, reglas de negocio y decisiones técnicas.

## Consecuencias

- Cada implementación deberá actualizar documentación afectada.
- Las decisiones relevantes se registrarán como ADR.
- El avance inicial será más controlado, aunque no produzca código en Fase 0.
